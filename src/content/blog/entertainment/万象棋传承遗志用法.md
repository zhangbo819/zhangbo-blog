万象棋传承遗志用法

## 1. 马克养镜、曜

阵容通常是，香香，镜/曜，猪，一个其他高等级（牛、姬小满、芈月）

### 情况一：马克经典换吕布 （经典场景）

通常都会有1遗志1换帅，传承可能0-2，传承越多肯定最后等级越高，但不影响核心

手里最少1遗志1换帅1吕布，传承0-2张

1. 有传承的情况，先传承，将其他英雄等级给到最后的曜和孙尚香，损失一些也没事
2. 对曜、镜使用遗志，将等级稳定给到孙尚香
3. 最后场上只有孙尚香，上吕布，对他使用换帅

最后留下： 1个高等级吕布

吕布等级 = （香香+镜/曜）（至少500+） + 传承其他

### 情况二：换其他非三分大哥

通常镜/曜+香香的等级特别高时使用

手里要有一张遗志、一张传承、一张任意大哥

1. 将其他棋子卖掉，留 镜/曜 + 香香 + 其他高等级棋子（有第二张传承的话）
2. 先上1级大哥在场上
3. 传承高等级棋子卖掉
4. 再传承香香卖掉
5. 遗志镜/曜给大哥
   
最后留下: 1个高等级大哥

大哥等级 = 镜/曜 + 香香 + 其他高等级棋子 - 最后1次传承的损耗

## 2. 三分登场

和马克类似，不过传承更多，遗志不一定有

假设场上有6-7人，通常是，曹操、蔡文姬、小乔、甄姬、周瑜、貂蝉、打出位（可能是露娜、香香、赵云、吕布）

> 这里分析一下最后应该留谁
> 
> 从换完继续刷的角度，应该留 二级英雄，因为在六本在商店刷到二级英雄概率更小，所以应该留曹操、蔡文姬
> 而曹操 > 蔡文姬，因为有曹操还可以触发整备进行倒转，蔡文姬偏向于加等级
> 
> 再然后 4费卡 小乔、甄姬
>
> 从增加战斗力的角度，应该留 蔡文姬 > 曹操 > 甄姬/小乔
> 最后场上的高战力应该是 吕布、周瑜、貂蝉，其他

### 情况一：场上等级不高（250级左右），且吕布不在场（经典场景）

手里1遗志，1换帅，1吕布，传承 0-2 张

1. 卖出场上最低的3个棋子，最后只留4个级最高的棋子
2. 2次传承给最低的两个棋子
3. 场上只有两个，遗志给一个
4. 场上只有一个，上吕布换帅

最后留下： 1个高等级吕布

吕布等级 = 250 * 2 + 传承其他（0-500级）- 最后1次传承的损耗


### 情况二：场上等级不高（250级左右），吕布不在场，无遗志（损耗较大）

手里 1换帅，1吕布，传承2张

1. 等级低的全卖掉，只留三张级最高的
2. 传承给最低的棋子传承完卖掉
3. 场上只有一个，上吕布换帅

最后留下： 1高等级吕布

吕布等级 = 250 + 传承其他 2次（0-500级）


### 情况三：场上等级不高（250左右），吕布在场，非超级换帅 （吕布提前上场并无法超级换帅）

这种情况应该把其余棋子等级尽可能向吕布身上集中

手里传承遗志任意

这里先假设1遗志，2传承

1. 卖掉打出位特低等级1个棋子
2. 场上还有6个，其中有一个吕布
3. 先再卖掉两个级最低的，此时还剩下4个
4. 传承一个卖掉，还剩下3个
5. 再传承一个卖掉，还剩下2个
6. 遗志一个给到吕布

最后留下：1个高等级吕布

吕布等级 =  250 + 遗志（最少250）+ 传承两次其他（0-500）


### 情况四：场上等级不高（250左右），吕布不在场，超级换帅 （副作用最小且等级不低）

此时一般都是已经打过大招奇才加几次切了，这时候等级通常已经超过250了

假设：手里5张吕布（白歌3张），2换帅，传承遗志任意

1. 先卖出打出位的，级特别低的，空出打出位让吕布有位置上场
2. 场上还剩下6个棋子
   1. 可选：遗志，传承
   2. 等级不高且想凑一个大哥时，先传承，卖掉，再传再卖，然后遗志，这样就稳定得到一个高等级棋子，供吕布换帅
   3. 想要不损失棋子继续刷时，传承一次，不卖，得到一个最高的棋子供吕布换帅
   4. 既想要高等级又想要尽可能支持后续刷时，先遗志小乔，再传承甄姬，不卖，然后得到一个高等级棋子，供吕布换帅
3. 上一个吕布换帅，再觉醒回手，记住等级
4. 再上一个吕布，和场上高等级三分棋子换帅
5. 再打出觉醒吕布，让两个吕布等级合并

最后留下：1个高等级吕布 + 原来的6个棋子（有遗志的话少一个，1个传承不少，2个传承再少一个）

吕布等级：250 * 2 + 传承遗志其他棋子（0-500级）


### 情况五： 场上等级比较高（500级以上），吕布不在场

通常是有露娜的高等级三分登场或者三分倒转后期

手里 1遗志1换帅，1吕布

1. 遗志给一个非三分的棋子，如果都是三分且最低的都大于500，则给一个最低的，如果有露娜等级低的，卖掉一个
2. 遗志给到的三分棋子达到接近满级
3. 上吕布，换帅这个棋子

最后留下： 1高等级吕布 + 5个原来的棋子


## 3.刺客三分倒转

阵容通常是，曹操、甄姬、小乔、阿珂、猴子、周瑜、露娜

> 刺客三分的情况，在后期等级比较高时，优先走阿珂，露娜可以留也可以不留
> 
> 露娜也是刺客，可以吃到猴子整备
> 
> 但不卖露娜再次刷到露娜的概率降低，适合有宝盒天赋、卡同行露娜，或者非李白这种能够持续爆发的棋手使用
>
> 如果卖露娜则留阿珂，将等级刷到500以上，再遗志传承阿珂，换帅吕布

### 情况一：场上等级适中（300级左右），吕布不在场

手里有 1遗志、1传承、1换帅、1吕布

这种情况一般是孙膑打完两次回环，或者白歌爆发2-3次时需要变阵时

1. 先遗志阿珂，场上还有6个人
2. 如果阿珂等级给到了三分棋子，则直接换帅
3. 如果阿珂等级给到了猴子，且看对面阵容猴子用处不大时，传承猴子，对等级分到多的人换帅
4. 如果想要等级尽量高些
   1. 先卖掉两个最低的棋子
   2. 遗志阿珂
   3. 此时场上还有4个
   4. 传承一次，不卖，将最高的换帅吕布
   5. 也可以传承一次，卖掉，再传承一次，不卖，再换帅吕布

### 情况二：场上等级比较高（500级以上），吕布不在场，无遗志

手里 1-2传承1换帅，1吕布

1. 如果有打出位级特别低的，先卖掉
2. 传承最低的棋子，1-2次，出现满级则可以停止
3. 上吕布，换帅
